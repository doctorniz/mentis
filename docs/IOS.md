# iOS

The iOS app is the same Tauri shell as the desktop and Android apps, for
iPhone and iPad. It needs a Mac to build; CI builds it on a macOS runner.

- **Bundle id:** `app.mentis` (`src-tauri/tauri.ios.conf.json`), iOS 17 or
  later.
- **Front end:** `vite build --mode mobile`, as on Android.
- **Xcode project:** `src-tauri/gen/apple`, generated by `tauri ios init` and
  committed. `src-tauri/Info.ios.plist` is merged into its `Info.plist`.
- **Swift:** a small plugin crate, `src-tauri/plugins/folders` (Rust in
  `src/`, a Swift package in `ios/`). Tauri's build step compiles and links the
  package.

Not built yet: reminders, shares and the widget, Dropbox sign-in, on-device
AI. Their commands answer with nothing on iOS.

## Vaults

A vault is either:

- **In the app's folder** — what _New vault_ creates. Files shows it as
  _On My iPhone › Mentis_ (`UIFileSharingEnabled`,
  `LSSupportsOpeningDocumentsInPlace`), so other apps can open the notes too.
  The folder moves when the app is reinstalled or updated, so these vaults are
  kept as `~/Documents/<name>` and resolved at each use
  (`vault_fs::root_path`).
- **A folder picked in Files** — _Open a folder_: on the device, iCloud Drive,
  or another provider's folder. iOS lets the app use it only while holding
  access, and after a restart only through a bookmark saved when it was
  picked. `FoldersPlugin.swift` keeps the bookmarks (in the app's
  `UserDefaults`) and reopens them at launch (`vaults::restore_picked`); a
  folder that moved is followed.

Once open, either kind is an ordinary path: the same Rust file commands as on
the desktop read and write it, with no per-file bridge as on Android.

- No file watching: as on Android, the vault is reconciled whenever the app
  comes back to the foreground.
- **iCloud Drive:** a file iOS has offloaded (a cloud icon in Files) is a
  placeholder until downloaded, and does not open yet.

## Building and running (on a Mac)

Once:

```bash
xcode-select --install            # and Xcode from the App Store
brew install xcodegen
rustup target add aarch64-apple-ios aarch64-apple-ios-sim
pnpm install
pnpm tauri ios init               # makes src-tauri/gen/apple; commit it
```

Then:

```bash
pnpm tauri ios dev                # pick a simulator, or a connected iPhone
pnpm tauri ios build --debug --target aarch64-sim
```

A real iPhone needs a signing team: a free personal team in Xcode works for a
week at a time; the Apple Developer Program for longer, and for TestFlight.
Set it as `APPLE_DEVELOPMENT_TEAM` or `bundle.iOS.developmentTeam`.

The web view can be inspected from Safari on the Mac (Develop menu) in a
debug build.

## CI

The `ios` job (`.github/workflows/ci.yml`) builds for the simulator, launches
the app, checks it is still running after 20 s, and keeps a screenshot of the
first screen (`ios-first-screen` artifact). Until `src-tauri/gen/apple` is
committed it generates the project and keeps it as an artifact too.
