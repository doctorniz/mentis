# iOS

The iOS app is the same Tauri shell as the desktop and Android apps, for
iPhone and iPad. It needs a Mac to build; CI builds it on a macOS runner.

- **Bundle id:** `ink.mentis.app` (`src-tauri/tauri.ios.conf.json`), iOS 17 or
  later.
- **Front end:** `vite build --mode mobile`, as on Android.
- **Xcode project:** `src-tauri/gen/apple`, generated by `tauri ios init` and
  committed. `src-tauri/Info.ios.plist` is merged into its `Info.plist`.
- **Swift:** a small plugin crate, `src-tauri/plugins/folders` (Rust in
  `src/`, a Swift package in `ios/`). Tauri's build step compiles and links the
  package.

Not built yet: reminders, shares and the widget, Dropbox sign-in. Their
commands answer with nothing on iOS, and the controls that would need them are
left out there (`isIosApp()` in `src/lib/fs/platform.ts`): the Sync tab in
Settings, the Reminders tab in Calendar, and a task's Remind at time.

## Plain http

App Transport Security allows plain `http://` to local addresses only
(`NSAllowsLocalNetworking`), for Ollama on the LAN; the first request asks
for local network access (`NSLocalNetworkUsageDescription`).

## Privacy manifest

Apple requires every app to declare the system APIs it uses and what it
collects. `src-tauri/gen/apple/mentis_iOS/PrivacyInfo.xcprivacy` declares file
times, `UserDefaults` (the folder bookmarks), boot time (timers) and disk
space, and no tracking or collected data. It must match what the app does and
what <https://mentis.ink/privacy> says; if Apple's upload email names another
API, add it there.

## App icon

The icon is the brain from `public/icon.svg`, in `src-tauri/gen/apple/Assets.xcassets/AppIcon.appiconset` (also kept in `src-tauri/icons/ios`). iOS wants it square, full-bleed and with no alpha channel (the 1024 px marketing icon is rejected otherwise): render the SVG without its `rx` rounding at 1024 px, run `pnpm tauri icon <that png> -o <temp dir>`, strip the alpha from `ios/*.png`, and copy them over both folders. The Xcode project is committed, so `tauri ios init` does not run again and will not replace them. Until 0.1.4's build 4 the project held Tauri's default logo.

## Microphone and camera

Voice notes and _Take photo_ need `NSMicrophoneUsageDescription` and
`NSCameraUsageDescription` (`src-tauri/Info.ios.plist`); iOS closes an app
that asks for either without them.

## Vaults

A vault is either:

- **In the app's folder** — what _New vault_ creates. Files shows it as
  _On My iPhone › Mentis_ (`UIFileSharingEnabled`,
  `LSSupportsOpeningDocumentsInPlace`), so other apps can open the notes too.
  The folder moves when the app is reinstalled or updated, so these vaults are
  kept as `~/Documents/<name>` and resolved at each use
  (`vault_fs::root_path`).
- **A folder picked in Files** — _Open a folder_: on the device, iCloud Drive,
  or another provider's folder. iOS lets the app use it only while holding
  access, and after a restart only through a bookmark saved when it was
  picked. `FoldersPlugin.swift` keeps the bookmarks (in the app's
  `UserDefaults`) and reopens them at launch (`vaults::restore_picked`); a
  folder that moved is followed.

Once open, either kind is an ordinary path: the same Rust file commands as on
the desktop read and write it, with no per-file bridge as on Android.

- No file watching: as on Android, the vault is reconciled whenever the app
  comes back to the foreground.
- **iCloud Drive:** a file iOS has offloaded (a cloud icon in Files) is a
  placeholder until downloaded, and does not open yet.

## Building and running (on a Mac)

Once:

```bash
xcode-select --install            # and Xcode from the App Store
brew install xcodegen
rustup target add aarch64-apple-ios aarch64-apple-ios-sim
pnpm install
pnpm tauri ios init               # makes src-tauri/gen/apple; commit it
```

Then:

```bash
pnpm tauri ios dev                # pick a simulator, or a connected iPhone
pnpm tauri ios build --debug --target aarch64-sim
```

A real iPhone needs a signing team: a free personal team in Xcode works for a
week at a time; the Apple Developer Program for longer, and for TestFlight.
Set it as `APPLE_DEVELOPMENT_TEAM` or `bundle.iOS.developmentTeam`.

The web view can be inspected from Safari on the Mac (Develop menu) in a
debug build.

## TestFlight

`.github/workflows/testflight.yml` signs and uploads a build
([`DEPLOYMENT.md`](./DEPLOYMENT.md), TestFlight).

## CI

The `ios` job (`.github/workflows/ci.yml`) builds for the simulator, launches
the app, checks the privacy manifest is in it and that it is still running
after 20 s, and keeps a screenshot of the first screen (`ios-first-screen`
artifact). The project is committed; if `src-tauri/gen/apple` were missing the
job would generate it and keep it as an artifact.
